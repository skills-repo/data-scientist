## 使用约定

1. 任何新指标上线前，必须先在此登记，**登记后才能进报表**。
2. 口径变更必须**新增版本行**，不得原地覆盖——历史数据的解释依赖历史口径。
3. 口径变更后，所有引用该指标的看板需标注变更时点，避免读者把口径断层当成业务波动。
4. 指标名一旦发布不再改名。要改，就新建一个指标并标注旧指标为「已弃用」。

## 常见陷阱速查

| 陷阱 | 表现 | 处理 |
|---|---|---|
| **比率的分母漂移** | 转化率涨了，其实是分母（曝光）在跌 | 分子分母必须同时展示 |
| **平均值的平均值** | 各分组转化率求平均得到总转化率 | 重算 Σ分子 / Σ分母 |
| **口径断层当波动** | 某天指标跳变，其实是口径改了 | 看板标注口径变更时点 |
| **指标腐化** | 指标被当成 KPI 后被针对性优化，与真实价值脱钩 | 配对护栏指标，定期复核指标有效性 |
| **迟到数据** | 昨天的数字今天还在变 | 标注数据成熟度，未成熟的用虚线 |
| **时区混用** | 日活按 UTC 切，业务按北京时间看 | 统一时区并在字典写死 |
| **幸存者口径** | 只统计留存用户的满意度 | 明确人群定义，说明排除了谁 |
