# 图表交付前审查清单

> 配套 [references/data-visualization.md](../references/data-visualization.md)。
> 每张要给别人看的图，交付前逐条过一遍。**打不满的项要么改图，要么在图注里交代。**

---

## 一、这张图该不该存在

- [ ] 它回答了一个**具体问题**，而不是"把数据展示一下"
- [ ] 标题写的是**结论**（"移动端转化率连续 3 周下滑"），不是**主题**（"转化率趋势"）
- [ ] 如果只有 3 个数字，我确认过表格是不是比图更清楚
- [ ] 这张图删掉之后，报告的结论会缺一块（如果不会，就删掉）

## 二、图表选型

| 想表达 | 该用 | 别用 |
|---|---|---|
| 随时间变化 | 折线图 | 饼图、堆叠面积（除非关心总量） |
| 类别间比较 | 条形图（横向，标签好读） | 雷达图、词云 |
| 构成占比 | 堆叠条形 / 树图 | 3D 饼图、超过 5 类的饼图 |
| 两变量关系 | 散点图 | 双 Y 轴折线 |
| 分布形态 | 直方图 / 箱线图 / 小提琴图 | 只报均值的条形图 |
| 排名 | 横向条形（按值排序） | 折线图（类别间无顺序） |

- [ ] 选型符合上表，或有明确理由偏离
- [ ] 类别数 > 7 时，已合并长尾为「其他」或改用条形图
- [ ] **没有使用双 Y 轴**——双 Y 轴的相关性可以靠调整刻度任意伪造。
      确需对比两个量纲，改用双子图或指数化（都设为基期 = 100）。

## 三、坐标轴与刻度（造假重灾区）

- [ ] **条形图的 Y 轴从 0 开始**。条形靠长度编码数值，截断即失真。
- [ ] 折线图 Y 轴若不从 0 开始，已在图上明确标注截断
- [ ] 坐标轴有**单位**（元 / % / 人 / 次），不是光秃秃的数字
- [ ] 大数字已做可读化（1,200,000 → 120 万），且单位写在轴标题里
- [ ] 时间轴**间隔均匀**，没有跳过缺失日期造成的虚假平滑
- [ ] 对数轴（如使用）已显式标注，否则读者会按线性读
- [ ] 百分比轴上限合理，没有为了显得变化大而压缩到 [48%, 52%]

## 四、五种最常见的误导（逐条排除）

1. **截断 Y 轴** → 把 0.3pp 的波动画成悬崖
   - [ ] 已排除
2. **选择性时间窗** → 只画上涨的那三个月
   - [ ] 时间窗有业务理由，不是挑出来的
3. **双 Y 轴伪相关** → 两条线"高度相关"，其实是刻度凑的
   - [ ] 未使用双 Y 轴
4. **面积/体积编码线性量** → 半径翻倍，面积变 4 倍，视觉夸大
   - [ ] 气泡图按**面积**而非半径编码
5. **缺失分母** → 只画绝对值增长，掩盖了基数也在涨
   - [ ] 比率与绝对值同时提供，或已在图注说明

## 五、颜色

- [ ] 颜色**承载信息**，不是装饰。同一含义在所有图中用同一颜色。
- [ ] 顺序型数据用**单色渐变**，发散型（有中点）用**双色发散**，
      类别型用**离散色板**——没有把类别数据涂成彩虹渐变
- [ ] **色盲友好**：红绿对比已改为蓝橙，或额外用形状/标注区分
- [ ] 灰度打印仍可读（明度有差异，不只靠色相）
- [ ] 强调色只给**一个**重点，其余用灰。全部高亮 = 没有重点。
- [ ] 涉及涨跌：遵循国内习惯，**涨用红、跌用绿**

## 六、去除 chartjunk

- [ ] 无 3D 效果、无阴影、无渐变填充、无纹理背景
- [ ] 网格线是浅灰细线，或直接删除
- [ ] 无图表边框、无多余背景色块
- [ ] 图例位置不遮挡数据；类别少时**直接标注在数据旁**，删掉图例
- [ ] 数据标签只标关键点（首尾、峰值、拐点），不是每个点都标

## 七、注释与上下文

- [ ] 关键拐点有**文字注释**说明发生了什么（"3/15 改版上线"）
- [ ] 有基准线 / 目标线 / 去年同期作为参照
- [ ] 数据来源、统计口径、截止时间写在图注
- [ ] 样本量小的分组已标注 n（"n=23" 提醒读者别过度解读）
- [ ] 口径变更时点已用竖线标出，避免读者把口径断层当业务波动
- [ ] 未成熟数据（迟到数据未回齐）用虚线或浅色区分

## 八、仪表盘专项

- [ ] 遵循**倒金字塔**：最重要的指标在左上，细节在下方
- [ ] 单屏可见核心结论，不需要滚动
- [ ] 每个指标有**对比基准**（环比 / 同比 / 目标），孤零零一个数字没有意义
- [ ] 不同图表的时间范围一致，或差异已明确标注
- [ ] 指标定义可追溯到指标字典（鼠标悬停或脚注）
- [ ] 卡片数量 ≤ 9。塞满 20 个指标的看板等于没有看板。

## 九、最后一步：找人试读

把图给一个**没参与分析的人**看 10 秒，然后问：

1. 这张图在说什么？
2. 最重要的数字是多少？
3. 你觉得该做什么？

- [ ] 对方的回答与我的意图一致

如果不一致，问题在图，不在读者。改图。
