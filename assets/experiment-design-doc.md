## 6. 已知风险与污染源

| 风险 | 说明 | 缓解 |
|---|---|---|
| SRM | 分流实现有 bug / 埋点丢失不对称 | 每日跑 `ab_test_calc.py srm` |
| 新奇效应 | 用户对新界面短期好奇，效果会衰减 | 观察效应随时间的趋势，别只看均值 |
| 溢出效应 | 实验组影响到对照组 | {{改用聚类随机化 / 评估污染程度}} |
| 交互实验 | 同期其他实验作用于同批用户 | 登记实验冲突表，检查重叠度 |
| 埋点变更 | 实验期间埋点改版 | 冻结埋点，或记录变更时点 |

## 7. 分析计划（预注册）

1. **健康检查**：SRM 检验（p < 0.001 判定分流异常 → 结果作废，先修分流）
   ```
   python3 scripts/ab_test_calc.py srm --counts {{n_a}} {{n_b}} --expected 0.5 0.5
   ```
2. **主指标检验**：
   - 比率型：`ab_test_calc.py prop --a-n {{}} --a-x {{}} --b-n {{}} --b-x {{}}`
   - 均值型：`ab_test_calc.py mean --a-n {{}} --a-mean {{}} --a-sd {{}} --b-n {{}} --b-mean {{}} --b-sd {{}}`
3. **报告内容**：效应量 + 95% 置信区间 + p 值。**三者缺一不可**。
   - 只报 p 值等于没报——读者无法判断这个提升值不值得上线。
4. **护栏指标**：逐个检查是否恶化。
5. **异质性分析**：{{预先声明要看哪些细分维度}}
