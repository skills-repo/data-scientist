## 7. 故障处理

### 常见故障速查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 任务超时 | 数据倾斜 / 上游暴增 / 资源被抢 | 看 key 分布，确认是否需加盐；检查资源队列 |
| 行数骤降 | 上游断供 / 过滤条件误伤 / 分区没写对 | 先查上游分区，再查 WHERE 条件 |
| 行数翻倍 | JOIN 一对多 / 重复加载 | 验 JOIN key 唯一性；检查是否 INSERT INTO 追加 |
| 主键重复 | 上游产生重复 / 去重逻辑失效 | 用 ROW_NUMBER 去重前先查清重复来源 |
| 指标口径突变 | 上游口径改了 / 本管道逻辑改了 | 对比变更记录，通知下游标注断层 |

### 处理流程

1. **止血**：阻断下游，避免脏数据扩散。必要时回滚到上一个好分区。
2. **通知**：告知下游消费方（清单见文首），说明影响范围与预计恢复时间。
3. **定位**：查调度日志 → 查上游就绪状态 → 查数据质量报告。
4. **修复**：修逻辑或等上游修复。
5. **回填**：按第 4 节流程重跑受影响分区。
6. **验证**：质量门禁通过 + 与下游核对至少一个关键指标。
7. **复盘**：填写下方记录，把新发现的检查项加进质量规则。
