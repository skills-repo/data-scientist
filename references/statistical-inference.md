# 统计推断

> 推断的全部目的：区分**"数据里的模式"**和**"世界里的规律"**。
> 大部分错误结论不是算错了统计量，而是把"没证据说明有差异"当成了"证明没有差异"。

## 一、p 值到底是什么（以及不是什么）

**p 值 = 假设"真的没有差异"，观察到当前或更极端结果的概率。**

它**不是**：

| 常见误读 | 为什么错 |
|---------|---------|
| "p=0.03 说明有 97% 概率存在真实效应" | p 值是给定"无效应"下的数据概率，不是"有效应"的概率。要回答后者需要贝叶斯 + 先验 |
| "p=0.06 说明没有效应" | 只说明证据不足。样本量小的时候，很大的真实效应也可能 p>0.05 |
| "p 越小效应越大" | p 值同时受效应量和样本量影响。样本量足够大时，微不足道的差异也能 p<0.001 |
| "两组各自与对照比，一组显著一组不显著 ⇒ 两组有差异" | 必须直接比较两组，"显著性的差异"不等于"差异的显著性" |

**0.05 没有任何神圣性**。它是 Fisher 随手定的惯例。真正该问的是：
这个效应量在业务上值不值得行动？决策成本和犯错代价是多少？

## 二、效应量与置信区间比 p 值重要得多

只报 p 值等于只说"有没有"，不说"有多少"。业务决策需要的是后者。

```
差的报告：转化率有显著提升（p < 0.05）
好的报告：转化率从 3.20% 提升到 3.45%，绝对提升 0.25pp（相对 +7.8%），
          95% CI [0.05pp, 0.45pp]，预计年增收 ¥120 万 ± ¥50 万
```

**置信区间的正确解读**：如果重复这个实验很多次，95% 的区间会包含真值。
不是"真值有 95% 概率落在这个区间"（那是贝叶斯可信区间）。

置信区间的实用价值在于**同时回答显著性和实际意义**：

- 区间不含 0 → 统计显著
- 区间**整体**都在业务最小可接受效应之上 → 值得上线
- 区间横跨 0 且很宽 → 样本量不足，继续收集数据而不是下结论
- 区间很窄且贴近 0 → **有把握地证明效应可以忽略**，这是有价值的结论

## 三、选对检验方法

| 数据类型 | 场景 | 方法 | 注意 |
|---------|------|------|------|
| 两组比例 | A/B 转化率 | 双比例 z 检验 / 卡方 | 每组期望频数 ≥5；否则用 Fisher 精确检验 |
| 两组均值 | 客单价、时长 | Welch's t 检验 | **默认用 Welch，不要用等方差 t 检验**——不需要假设方差相等，代价几乎为零 |
| 两组分布 | 长尾指标 | Mann-Whitney U | 比较的是分布位置而非均值，对长尾更稳健 |
| 多组均值 | 多版本对比 | ANOVA + 事后检验 | 必须做多重比较校正 |
| 配对数据 | 同一批人前后 | 配对 t 检验 / Wilcoxon | 配对能大幅降低方差，别当成独立样本 |
| 类别关联 | 渠道 × 是否转化 | 卡方独立性检验 | 只说明有关联，不说明方向和强度 |
| 计数数据 | 每用户下单次数 | Poisson / 负二项回归 | 计数数据方差常大于均值（过离散），用负二项 |

**长尾指标的特别提醒**：收入、时长、订单金额几乎都是重尾分布。
均值检验在重尾下收敛极慢，几个大客户就能左右结论。可选做法：
1. 同时报告中位数和分位数的差异
2. 对指标做 winsorize（截尾至 P99）后再检验，并说明截了多少
3. 用 bootstrap 直接对目标统计量（哪怕是中位数、P90）构造置信区间——最通用

## 四、多重比较：看得越多，越容易看到假的

做 20 次独立检验，即使全部无效应，平均也会有 1 次 p<0.05。

**什么时候会不知不觉做了多重比较**：
- 看了 10 个指标，只报告显著的那个
- 按渠道/设备/地区切了 15 个细分人群
- 实验跑了 14 天，每天都看一眼有没有显著

校正方法：

| 方法 | 控制什么 | 适用 |
|------|---------|------|
| Bonferroni（α/m） | 族错误率 FWER | 检验数少（<10）、要求严格 |
| Holm | FWER，比 Bonferroni 有力 | 通用替代 Bonferroni，无理由不用它 |
| Benjamini-Hochberg | 错误发现率 FDR | 检验数多（探索性分析、几十上百个指标） |

**更根本的解法**：实验开始前就声明**一个主指标**，其余全部标为探索性指标。
探索性指标发现的东西只能作为下一次实验的假设，不能直接作为结论。

## 五、样本量与检验力：在开始前算，不是结束后算

检验力（power）= 真的有效应时，能检测出来的概率。行业惯例 80%。

**双比例检验的样本量近似公式**（每组）：

```
n ≈ 16 × p̄(1 - p̄) / δ²

p̄  = 两组预期比例的均值
δ  = 想检测出的最小绝对差异（MDE）
16 ≈ 2 × (1.96 + 0.84)²，对应 α=0.05 双侧、power=80%
```

例：基线转化率 3%，想检测 0.3pp 的绝对提升
→ n ≈ 16 × 0.03 × 0.97 / 0.003² ≈ 51,733 每组

用 `scripts/ab_test_calc.py --power-analysis --baseline 0.03 --mde 0.003` 直接算。

**三个关键认知**：
1. **MDE 减半，样本量变 4 倍**。想检测微小效应的代价是二次增长的。
2. **样本量不够时不要开实验**。跑一个 power=30% 的实验，即使真有效应也有 70% 概率白跑，
   而"没显著"还会被误读为"没效果"。
3. **事后检验力分析（post-hoc power）没有意义**。它只是 p 值的单调变换，不提供新信息。
   要评估阴性结果，看置信区间的宽度和上下界。

## 六、常见推断陷阱

### 回归到均值
极端值下一次观测会自然向均值靠拢。"给表现最差的门店做培训，之后业绩提升了"——
不做培训它也会提升。**没有对照组的前后对比几乎总是错的**。

### 辛普森悖论
见 `exploratory-analysis.md`。在推断层面的表现是：合并数据显著为正，分组后每组都为负。
处理方式是把分组变量作为协变量纳入，或分层分析后合并（Mantel-Haenszel）。

### 幸存者偏差与选择偏差
"用了我们产品的用户留存率更高"——是产品起作用，还是本来就想留下的人才会用？
观察性数据要做因果推断，必须处理混杂：倾向性得分匹配、双重差分、工具变量。
**能做实验就做实验**，这些方法都是退而求其次。

### 中介变量误用
控制了处于因果路径上的中间变量，会把真实效应抹掉。
不是"控制的变量越多越好"——控制错变量比不控制更糟。

### 数据窥探（p-hacking）
换指标、换人群、换时间窗，直到 p<0.05。这不需要主观恶意，
"再多看两个维度"就足以发生。防御是**分析计划先于数据**：
在看结果前写下主指标、人群定义、检验方法和停止规则。

## 七、贝叶斯视角：什么时候更合适

频率派回答"假设无效应，数据有多罕见"；贝叶斯回答"给定数据，效应是多少的概率分布"。

贝叶斯更适合的场景：
- **需要连续监控**。贝叶斯后验可以随时看，不像频率派峰值窥探会膨胀假阳性
- **需要直接的决策概率**。"B 优于 A 的概率是 93%"比 p 值更容易向业务方解释
- **有可靠先验**。同类实验做过很多次，历史效应量分布就是好先验
- **样本量小**。先验能提供额外信息

代价：先验的选择会影响结论，必须公开先验并做敏感性分析。
不要用贝叶斯来"救活"一个频率派下不显著的结果——那只是换个框架 p-hacking。

## 八、结论表述规范

无论方法如何，报告必须包含：

1. **效应量 + 置信区间 + 单位**（不只是 p 值）
2. **样本量与实际检验力**
3. **主指标是什么，何时声明的**（事前还是事后）
4. **做了多少次比较，是否校正**
5. **已知的偏差来源和局限**
6. **业务含义**：这个效应值不值得行动，成本收益如何

表述用词的准确性：

| 情况 | 该说 | 不该说 |
|------|------|--------|
| p<0.05，CI 不含 0 | "有证据表明存在提升" | "证明了有提升" |
| p>0.05，CI 很宽 | "证据不足，无法判断" | "没有效果" |
| p>0.05，CI 很窄且贴 0 | "有把握认为效应可忽略" | "两者相同" |
| 观察性数据的关联 | "存在关联" | "导致" / "带来" |
