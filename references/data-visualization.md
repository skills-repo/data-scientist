# 数据可视化

> 图表的唯一目的是**让读者以最小认知成本得到正确结论**。
> 好看不是目标，好看只是不干扰理解的副产品。任何"炫技"的图表都在为作者服务，而非读者。

## 一、先定结论，再选图表

顺序永远是：**结论 → 对比关系 → 图表类型 → 视觉编码**。

反过来做（先画一堆图再从中找结论）会产出大量无人阅读的仪表盘。

| 你要表达的关系 | 首选 | 备选 | 避免 |
|--------------|------|------|------|
| 随时间变化的趋势 | 折线图 | 面积图（强调累积量） | 柱状图（离散感割裂趋势） |
| 类别之间的量级比较 | 横向条形图 | 点图（类别多时） | 饼图 |
| 构成占比（静态） | 堆叠条形（单条） | 树图（层级多时） | 3D 饼图 |
| 构成随时间变化 | 堆叠面积图 / 百分比堆叠 | 多条折线 | 堆叠柱（读中间层极难） |
| 两个数值的关系 | 散点图 | 六边形分箱（点太多时） | 双 Y 轴折线 |
| 分布形状 | 直方图 | 密度图、箱线图、小提琴图 | 只报均值 |
| 多组分布对比 | 并排箱线图 | 山脊图 | 分组柱状图（丢失分布信息） |
| 相关性矩阵 | 热力图 | — | 散点矩阵（变量多时看不清） |
| 流转与转化 | 桑基图 / 漏斗图 | 阶梯条形 | — |
| 地理分布 | 分级填色图（率） / 气泡图（量） | — | 用填色图表达绝对量（面积大的省份被放大） |

**类别超过 7 个就用横向条形图并排序**。竖排柱状图的标签会挤在一起，
横排既能放下完整标签，又天然适合排序阅读。

## 二、Cleveland 感知精度层级

人眼对不同视觉编码的**读数精度**差异巨大，从高到低：

```
1. 共同基线的位置    ← 条形图、散点图（精度最高）
2. 无共同基线的位置  ← 堆叠图的中间层
3. 长度
4. 角度 / 斜率       ← 饼图在这里
5. 面积              ← 气泡图
6. 深浅 / 饱和度     ← 热力图
7. 色相              ← 只适合区分类别，不能表达大小
```

推论：
- **最重要的量必须用位置或长度编码**，不要用面积或颜色
- **饼图只在两三个类别、且只想说明"大约一半"这种粗略结论时可用**。
  需要精确比较就换条形图
- **气泡大小应映射到面积而非直径**，否则视觉上会放大平方倍
- **颜色深浅最多传达 5-7 个可分辨等级**，超过就该改用位置编码

## 三、五种最常见的误导（也是审图检查项）

### 1. Y 轴截断
柱状图 Y 轴不从 0 开始，会把 2% 的差异画成 3 倍差距。

规则：**柱状图/面积图的 Y 轴必须从 0 开始**（长度编码，截断即扭曲）；
折线图可以截断（位置编码，读的是变化），但必须**明确标注**。

### 2. 双 Y 轴
两条不同量纲的线放一张图，交叉点完全取决于两个轴的缩放选择——
调整刻度就能造出任意的"相关性"。

替代方案：上下两个共享 X 轴的子图，或都转成指数（以某时点为 100）。

### 3. 缺失分母
"某地区订单增长 300%"——基数是 2 单。永远同时呈现比率和绝对量。

### 4. 未成熟数据
最近 1-3 天数据未回齐、最新 cohort 未到观察期，画上去就是一个虚假的断崖下跌。
处理：**截掉未成熟区间，或用虚线/灰色明确标注**。

### 5. 选择性时间窗
从最低点开始画，任何东西都在上涨。默认展示足够长的历史，让读者自己判断趋势的稳定性。

## 四、颜色使用规范

**三种色板，对应三种数据**：

| 数据类型 | 色板 | 例子 |
|---------|------|------|
| 分类（无序） | 定性色板，色相不同、明度接近 | 不同产品线 |
| 顺序（单向） | 单色渐变，明度单调变化 | 销量从低到高 |
| 发散（有中点） | 双色发散，中间为中性色 | 同比增减、正负偏差 |

硬性要求：

- **色相不能表达大小**。红色不比蓝色"更多"。
- **必须通过色盲检查**。约 8% 男性有红绿色盲。
  避免红-绿对立配色，改用蓝-橙；或在颜色之外附加形状/纹理/直接标注冗余编码。
- **打印成灰度仍可读**。检验方法：把图转灰度看还能不能区分。
- **分类色不超过 6-7 种**。更多时把次要类别合并为"其他"，或改用小倍数图（small multiples）。
- **一致性**：同一份报告里，同一个类别在所有图中必须是同一个颜色。

**中国金融场景特别注意**：股票、财务涨跌的颜色约定与欧美相反——
**涨用红色，跌用绿色**。做金融相关图表时必须遵守本地约定，否则读者会读反。

## 五、去除图表垃圾（chartjunk）

Tufte 的数据墨水比原则：每一滴墨水都应该编码数据。删除清单：

- 3D 效果（无一例外地有害，透视会扭曲长度和面积）
- 背景网格线加粗、加深、加彩色 → 用极淡的灰色横线，或直接去掉
- 图表边框、面板阴影、渐变填充
- 冗余图例 → **能直接在线条末端标注系列名，就不要用图例**（省一次视线往返）
- 每个数据点都标数值 → 只标关键点（首尾、峰值、当前值）
- 与数据无关的装饰图片

**保留并强化**：坐标轴标签（含单位）、数据来源、时间范围、关键注释。

## 六、注释：把结论写在图上

一张图配一句结论式标题，胜过十行正文。

```
差：「2026 年各月销售额」          ← 描述图里有什么
好：「Q3 销售额同比转正，主要由新品贡献」 ← 说明读者应该得到什么结论
```

必要的注释元素：
- **结论式标题**：一句话说明这张图证明了什么
- **事件标注**：竖线 + 文字标出改版日、大促、故障、口径变更
- **参考线**：目标值、行业基准、历史均值
- **异常解释**：图上任何一个突刺，都应该在图内注明原因，否则读者会自行脑补

## 七、面向不同受众的取舍

| 受众 | 关注 | 图表策略 |
|------|------|---------|
| 高管 | 结论和行动 | 一页一个核心图，结论式标题，去掉所有技术细节，给出建议 |
| 业务方 | 能不能用、怎么用 | 分维度下钻，提供对比基准，标注口径 |
| 数据/技术同行 | 方法与可信度 | 保留置信区间、样本量、分布形态、异常处理说明 |
| 对外/公开 | 易懂与准确 | 最保守的可视化选择，充分标注来源与局限 |

**给高管的图不能省略不确定性**——但可以把它从误差棒改成一句话："该估计误差约 ±5%"。
省略不确定性是把判断风险转嫁给不知情的决策者。

## 八、仪表盘设计

仪表盘不是图表的堆放场，它有明确结构：

```
第一屏：3-5 个核心指标 + 同比环比 + 目标达成度（不需要滚动就能看完）
第二层：核心指标的趋势与主要拆解维度
第三层：明细下钻与异常清单
```

原则：
- **每个图回答一个问题**。答不上"这张图回答什么问题"就删掉
- **默认视图要有意义**。打开就是空白等你选筛选条件的仪表盘，没人会用
- **加载超过 5 秒就没人看**。预聚合，别在前端算
- **标注数据更新时间和口径**。这是仪表盘可信度的基础
- **定期做使用率审计**，把 3 个月无人访问的图表下线。仪表盘的最大成本是维护，不是开发

## 九、交付前检查清单

- [ ] 图表类型与要表达的关系匹配？
- [ ] 柱状图 Y 轴从 0 开始？折线图截断有标注？
- [ ] 有没有双 Y 轴（有就换掉）？
- [ ] 比率是否同时给了绝对量（分子分母）？
- [ ] 未成熟数据是否已截断或标注？
- [ ] 颜色通过色盲与灰度检查？金融涨跌色符合本地约定？
- [ ] 标题是结论而非描述？
- [ ] 坐标轴有单位？数据来源、时间范围、口径已标注？
- [ ] 关键异常点有解释？
- [ ] 缩小到实际展示尺寸（PPT/手机）后仍可读？
