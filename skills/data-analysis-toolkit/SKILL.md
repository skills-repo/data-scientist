# 数据分析工具包

> Excel/CSV 数据分析：洞察发现、统计计算、可视化图表、报告生成。

## 能力

- **探索式分析**：数据结构概览、分布检测、异常值识别
- **统计分析**：描述统计、相关性、回归分析、假设检验
- **数据可视化**：柱状图、折线图、散点图、热力图
- **报告生成**：数据概览、关键洞察、可视化图表、建议总结
- **公式与查询**：Excel 公式、透视表、数据筛选

## 使用方式

```
/data-analysis-toolkit 分析这个 CSV 数据的趋势和模式
/data-analysis-toolkit 给这个销售数据生成月度报告
/data-analysis-toolkit 找出这个数据集中的异常值
```

## 工作流

1. 加载和理解数据结构
2. 执行描述性统计分析
3. 识别趋势、异常、相关性
4. 生成可视化图表
5. 输出分析报告和建议

## 适用场景

- 业务数据探索和洞察
- 财务报表分析
- 用户行为数据解读
- 实验数据统计分析

## 限制

- 不涉及机器学习模型训练
- 不涉及大数据分布式计算
- 图表依赖用户提供数据格式
