# 数据分析工具箱

> 从数据中提取洞察：描述统计 → 可视化探索 → 假设检验 → 结论报告。不需要统计学学位，AI 帮你走完全流程。

## 能力

- **描述统计**：均值/中位数/标准差/分位数/分布形态，一键生成摘要
- **相关性分析**：Pearson/Spearman 相关系数，热力图，变量关系网络
- **假设检验**：t 检验、卡方检验、ANOVA，自动选最合适方法
- **趋势检测**：时间序列分解、移动平均、周期性检测
- **洞察报告**：自动生成数据分析报告，含图表和结论

## 使用方式

```
/data-analysis 分析这个销售数据，找出影响销量的关键因素
/data-analysis 用户行为数据中有没有显著的群体差异？
/data-analysis 帮我验证这个假设：周末客单价高于工作日
```

## 分析流程

1. **数据理解** — 导入数据，检查结构和质量
2. **探索性分析** — 描述统计 + 分布可视化
3. **假设生成** — 从数据模式中生成待验证假设
4. **统计检验** — 选择合适的检验方法
5. **结论报告** — 输出可读的分析报告

## 统计方法速查

| 问题类型 | 方法 | 何时用 |
|---------|------|-------|
| 两组均值差异 | t 检验 | 比较两组连续变量 |
| 多组差异 | ANOVA | 比较三组以上 |
| 分类变量关联 | 卡方检验 | 性别 vs 购买意愿 |
| 变量关系 | Pearson/Spearman | 收入 vs 消费 |
| 趋势是否存在 | Mann-Kendall | 时间序列趋势 |

## 适用场景

- 产品数据分析（用户行为、转化漏斗）
- 销售数据洞察（季节性、客户分群）
- A/B 测试结果分析
- 学术研究中的数据统计

## 限制

- 不替代专业统计软件（SPSS/SAS）
- 假设检验需满足基本前提（正态性、方差齐性等）
- 相关性不等于因果性 — 会标注但需使用者谨慎
